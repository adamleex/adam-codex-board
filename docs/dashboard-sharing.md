# Dashboard 只读分享

在 Dashboard 右上角点击「分享」→「启用分享」。这是整个看板的分享，包含所有项目的未归档任务；以后新增的项目和任务也会包含在内。

同事可以按项目筛选、搜索、切换看板和列表。可见字段仅有项目名称、任务状态、标题和描述；描述按纯文本展示为卡片摘要。公开响应不包含任务 ID、会话绑定、评论、附件、执行日志、负责人、日期或优先级，也没有任务详情入口。标题和描述中的文字会原样共享，请勿将不想分享的内容写入这两个字段。Markdown 不会生成链接或加载图片。

分享链接的持有者均可访问。点击「撤销分享」会使旧页面和 JSON 链接失效；再次启用会生成新链接。撤销不能收回别人已保存的内容。刷新分享页读取最新数据。

## 同事访问地址

默认只提供本机预览，不把 localhost 链接作为可外发链接。需要在公司允许的环境配置一个同事可访问的反向代理，**只代理 `/share/`，其余路径返回 404**。不要公开整个管理服务。

现有 SSH bridge 保持连接时，开发机上的 `127.0.0.1:47836` 可转发到本机服务；本机服务端口为 `47834`。开发机反向代理的上游可以使用前者。分享仍依赖本机 Dashboard 和 SSH bridge 在线，这个版本不是离线托管快照。

配置好代理后，在原启动终端停止 Dashboard，再运行：

```sh
npm run dashboard -- --share-origin https://YOUR-INTERNAL-HOST
```

将占位域名替换成实际地址。此命令仅保存地址，并不创建域名、代理、TLS 或公司登录。以后继续使用 `npm run dashboard` 即可。

公开路径：`GET /share/<token>`（看板）、`GET /share/<token>/tasks`（仅允许字段的 JSON）。管理路径 `/api/dashboard-share` 仍需原有启动器实例凭证或中央服务认证；该凭证不会写入分享页面或链接。
